English

Spanish localization of the D&D5e 2024 Cleric Domains compendium using Babele. It translates the Knowledge, Nature, and Tempest domain folders and visible text in all 19 documents while preserving stable IDs and game mechanics.

What’s translated?

  • Three Cleric domains: Knowledge, Nature, and Tempest.
  • Nineteen compendium documents: subclass descriptions and features, including visible source, activity, range, target, effect, and advancement text.
  • Native integration: preserves the base compendium, document identifiers, UUIDs, and mechanics; it does not create duplicate content.

Requirements

Foundry VTT 14.367+ (verified 14.370), dnd5e 6.0.3+ (verified 6.0.6), the D&D5e 2024 Cleric Domains base module 1.14.0+, the official Player’s Handbook 2024 module, and Babele 2.9.1+. Install each dependency separately.

Installation and activation

  1. Install and activate the base Cleric Domains module, the official PHB 2024 module, and Babele in your dnd5e world.
  2. Install this translation with the Manifest URL and enable it in the world.
  3. Select Español in Foundry’s language settings and reload the world.

Limitations

The translation changes visible text only. It does not add domains by itself or replace the base compendium. Actor documents previously imported from a compendium are not automatically synchronized after updates; update the base module before the translation.

Español

Traducción al español mediante Babele del compendio D&D5e 2024 — Dominios de Clérigo. Traduce las carpetas de Conocimiento, Naturaleza y Tempestad y los textos visibles de sus 19 documentos, conservando los ID estables y la mecánica de juego.

¿Qué contenido traduce?

  • Tres dominios de Clérigo: Conocimiento, Naturaleza y Tempestad.
  • Diecinueve documentos de compendio: descripciones de subclases y rasgos, incluidos textos visibles de fuente, actividades, alcance, objetivos, efectos y avances.
  • Integración nativa: conserva el compendio base, los identificadores de documentos, UUID y mecánicas; no crea contenido duplicado.

Requisitos

Foundry VTT 14.367+ (verificado 14.370), dnd5e 6.0.3+ (verificado 6.0.6), el módulo base D&D5e 2024 Cleric Domains 1.14.0+, el módulo oficial Manual del Jugador 2024 y Babele 2.9.1+. Cada dependencia se instala por separado.

Instalación y activación

  1. Instala y activa Cleric Domains, el PHB 2024 oficial y Babele en tu mundo dnd5e.
  2. Instala esta traducción con la URL del manifiesto y actívala en el mundo.
  3. Selecciona Español como idioma de Foundry y recarga el mundo.
