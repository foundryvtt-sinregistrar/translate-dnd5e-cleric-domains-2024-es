# D&D 2024 SubClasses - Cleric Domains — Traducción al español

Traducción Babele para **D&D 2024 SubClasses - Cleric Domains**.

Requiere Foundry VTT 14.367+, dnd5e 6.0.3+, el módulo base `dnd5e-2024-cleric-domains`, el PHB 2024 y Babele 2.9.1+. Activa los módulos, selecciona español como idioma de Foundry y recarga el mundo.

Traduce por ID estable las tres carpetas y los 19 documentos del compendio; no duplica ni sustituye el contenido original.

Los conversores Babele traducen únicamente los valores visibles de `source`, actividades, `range`, `target` y efectos, conservando intactos los campos mecánicos del módulo base. Los títulos visibles `Subclass Features` se presentan como `Rasgos de subclase` sin modificar los avances ni sus IDs almacenados.

El contrato completo de IDs está documentado en `LOCALIZATION.md` del módulo base. Antes de publicar una traducción ejecuta `npm test`; la prueba compara las 19 entradas, las tres carpetas y todos los IDs anidados contra `dnd5e-2024-cleric-domains/data/`.
