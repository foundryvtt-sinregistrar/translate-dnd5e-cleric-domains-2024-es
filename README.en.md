# D&D 2024 SubClasses - Cleric Domains — Spanish Translation

[Español](README.md) | **English**

Spanish Babele translation for **D&D 2024 SubClasses - Cleric Domains**. It translates the three folders and all visible fields of the 19 compendium documents by stable ID without duplicating the base documents.

## Requirements

- Foundry VTT 14.367 or newer (verified with 14.368).
- dnd5e 6.0.3.
- D&D 2024 SubClasses - Cleric Domains 0.0.2 or newer.
- Dungeons & Dragons Player's Handbook (PHB 2024).
- Babele 2.9.1 or newer.

## Installation

Use this manifest in Foundry:

```text
https://github.com/foundryvtt-sinregistrar/translate-dnd5e-cleric-domains-2024-es/releases/latest/download/module.json
```

Enable this module, the base module, Babele, the PHB 2024 module, and dnd5e. Select Spanish as Foundry's language and reload the world.

Published releases contain the installable ZIP, an external `module.json`, and `SHA256SUMS.txt`.
